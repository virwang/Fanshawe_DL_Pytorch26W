This is a food clasification project.
Orignial dataset: Food101 from kaggle.
Decrease it to defined 40 classes.

This project successfully identify 40 classes of dishes, and connect to the LLM AI for the identified food description.

Pre requirements for running this project:
Having food101.tar.gz saved in Google Drive
 
How to run this project?

1. Pre upload the app.py, food_best.pth file to Googel Colab content.
2. Run Project_UI.ipynb file.
3. Click the link that shows on the screen.
4. Insert the API key for food description.
5. Insert users' region for customize description.
